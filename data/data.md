# Data

En esta carpeta se encuentra el json de los museos, el cual tiene toda la *"Base de Datos"* a usar 
Se tratan de 8 museos categorizados por el tipo de museo que son, ademas de que tienen diferentes caracteristicas, que el usuario podria llegar a solicitar, para la salida a un museo

Ya que sabemos que este modelo no resuelve todo tipo de preguntas, tenemos un caso de qexclusion el cual envia al usuario a buscar mas informacion en la pagina del museo.
